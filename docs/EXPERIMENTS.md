# Experiments

Use this document to record reproducible strategy experiments.

## Experiment log

For each experiment, record:

- **Question:** What are you testing?
- **Change:** What changed from the baseline?
- **Method:** Which maps, seeds, opponents, and number of runs were used?
- **Results:** Include measurable outcomes and relevant observations.
- **Conclusion:** What did you learn, and what will you try next?
